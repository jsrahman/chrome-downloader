# Contributing to Okja YouTube Saver

Please see the full, comprehensive contributor guide in [**CONTRIBUTING.md**](CONTRIBUTING.md).

It covers:
- Core principles & architecture
- Prerequisites & local development setup
- Running the local companion service & debugging the extension
- Coding guidelines (Manifest V3 CSP, Python standard library, cross-platform rules)
- Running tests & quality checks (`npm test`)
- Building & packaging (`npm run build`)
- Pull request submission checklist
